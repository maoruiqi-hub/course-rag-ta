# 2～3 分钟演示脚本

## 准备

1. 启动应用：`streamlit run app.py`
2. 确认左侧显示 4 个样例资料（或提前上传自己的课程 PPT）
3. 浏览器窗口 1440×900，关闭无关标签页
4. 录制工具：Windows 游戏栏（Win+G）或 OBS

## 0:00–0:25 开场

> 这是「课程资料智能助教」，基于 LangChain 1.x 和 Streamlit。
> 它可以上传 PDF、PPTX、Word、TXT，生成摘要，并针对资料提问；
> 回答会标出文件名和页码，方便回到原文核对。

展示首页和左侧资料库。

## 0:25–0:55 文档总结

1. 切到「文档总结」
2. 选择 `demo_langchain.pptx`
3. 点击「生成摘要」
4. 说明：短文走 stuff；长文会自动走 map-reduce；右上角可以强制长文档模式

> 摘要按“核心概念 / 关键流程 / 重要结论 / 复习提示”组织，
> 可以下载 Markdown。

## 0:55–1:45 知识库问答

1. 切到「知识库问答」
2. 输入：`RAG 的两个核心组件是什么？`
3. 等待流式回答
4. 展开「引用来源」
5. 指出：来源卡片有文件名、页码、原文摘录和相关度

> 回答要求只依据检索资料；资料不足会说“根据当前资料无法确定”，
> 不会编造。多轮追问会先改写成独立问题再检索。

## 1:45–2:25 智能体

1. 切到「智能体」
2. 输入：`请计算 (128*3+7)/2，并告诉我现在北京时间。`
3. 展开「工具调用轨迹」
4. 指出：计算器和时间工具被调用，参数和返回值都可见

> 这里用的是 LangChain 1.x 的 create_agent，挂了三个工具：
> 知识库检索、计算器、当前时间。

## 2:25–2:45 收尾

> 项目还包含单元测试、GitHub Actions、RAG 评测和完整 README。
> 源码和运行说明在 GitHub 仓库：`maoruiqi-hub/course-rag-ta`。

展示 README 或仓库页面。

## 录制注意事项

- 不要展示 `.env`、API key 或浏览器书签栏；
- 如果 API 响应慢，先提前索引好资料，避免现场等待；
- 录屏分辨率 1440×900 或 1920×1080；
- 视频建议 2～3 分钟，控制在 50MB 以内；超过则放 GitHub Release 或外部链接。
